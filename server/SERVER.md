# Выделенный сервер Nitro Rush (Armbian, Debian, Ubuntu)

Сервер — это консольная сборка игры без графики и звука. Он держит лобби, симулирует ботов
и пересылает игрокам положение машин. Телефоны подключаются к нему по адресу, как к обычному хосту.

## Что нужно

**Железо.** Любая плата, на которую ставится Armbian: Orange Pi, Rock Pi, Raspberry Pi 3/4/5, Banana Pi, Tinker Board и т. п.
- Процессор: ARM64 (aarch64) или 32-битный ARMv7 (armhf). Годится даже Cortex-A53 на 1 ГГц: на гонку с 8 машинами уходит примерно 20–30% одного ядра.
- Память: от 512 МБ, сам сервер занимает около 100 МБ.
- Диск: около 70 МБ.
- Видеокарта, монитор и звук не нужны, сервер работает в режиме `--headless`.

**Система.**
- Armbian на Debian 10+ (Buster, Bullseye, Bookworm) или Ubuntu 20.04+ (Focal, Jammy, Noble). Нужна glibc 2.28 или новее.
- systemd. Он есть во всех обычных образах Armbian.

**Версии.** Игра на телефонах и сервер должны быть из **одного релиза**. При несовпадении сервер ответит «Версия игры не совпадает».

## Сеть

| Что | Значение |
|---|---|
| Порт игры | **UDP 24680** (меняется в настройках) |
| Поиск в локальной сети | UDP 24681, broadcast (нужен только для списка «Найденные игры») |
| Протокол | только UDP, TCP не нужен |
| Отдача сервера | 4 игрока и 3 бота — около 0.6 Мбит/с; 8 игроков и 6 ботов — около 2.5 Мбит/с. С запасом нужно **от 3 Мбит/с на отдачу** |
| Приём сервера | до 0.3 Мбит/с |
| У каждого игрока | отправка около 30 кбит/с, приём до 0.5 Мбит/с (мобильного интернета хватает) |
| Объём трафика | около 1 ГБ за час гонок полным составом |
| Пинг | комфортно до 80–100 мс |

Расчёт: каждая машина отправляет 20 обновлений в секунду, около 150 байт каждое.
Сервер пересылает их всем остальным, поэтому его отдача растёт как N×(N−1).
Замер на тестовом стенде (2 игрока и 2 бота): 22 КБ/с суммарно, 135 пакетов/с.

### Только локальная сеть (дома, Wi-Fi)

Плата и телефоны в одной сети. Больше ничего настраивать не нужно: сервер появится в списке
«Найденные игры» с пометкой `[сервер]`. Можно также ввести IP платы вручную.

### Игра через интернет

1. **Белый IP.** У домашнего интернета должен быть внешний («белый») IPv4-адрес.
   Проверка: адрес WAN в настройках роутера должен совпадать с адресом на сайте 2ip.ru или ifconfig.me.
   Если адрес в роутере вида `10.x.x.x`, `100.64–127.x.x`, `172.16–31.x.x` или `192.168.x.x`, значит провайдер раздаёт серый адрес (CGNAT),
   и порт снаружи не открыть. Варианты: заказать у провайдера белый IP (обычно платная услуга) или см. «Без белого IP» ниже.
2. **Постоянный адрес платы в сети.** Закрепите IP за платой в DHCP роутера (резервирование по MAC),
   например `192.168.1.50`.
3. **Проброс порта** на роутере (Port Forwarding / Виртуальный сервер):
   внешний порт **UDP 24680** → `192.168.1.50`, внутренний порт 24680, протокол **UDP**.
4. **Доменное имя (желательно).** Если внешний IP меняется, заведите бесплатный DDNS (DuckDNS, No-IP, встроенный в роутер Keenetic/ASUS/TP-Link)
   и раздайте друзьям имя вида `myrace.duckdns.org`.
5. **Подключение из игры:** «Мультиплеер» → поле «Адрес сервера» → `myrace.duckdns.org` (или `адрес:порт`, если порт не 24680) → «Подключиться».
   Адрес запоминается.

**Без белого IP:**
- VPN-сеть: Tailscale, ZeroTier или WireGuard. Плата и телефоны в одной виртуальной сети, подключение по VPN-адресу платы.
- Аренда VPS (это не Armbian, но сервер работает и там, есть сборка x86_64) с пробросом порта на плату через WireGuard.

## Установка

1. Скачайте из [Releases](https://github.com/lor3zer/php1611/releases) архив под архитектуру платы
   (узнать её: `uname -m`):
   - `aarch64` → `NitroRushServer-arm64.tar.gz`
   - `armv7l` → `NitroRushServer-armhf.tar.gz`
   - `x86_64` → `NitroRushServer-x86_64.tar.gz`
2. Установите:
   ```bash
   tar xzf NitroRushServer-arm64.tar.gz
   cd NitroRushServer
   sudo ./install.sh
   ```
   Скрипт создаст системного пользователя `nitrorush`, положит сервер в `/opt/nitrorush`,
   настройки в `/etc/default/nitrorush`, включит автозапуск и откроет порт в `ufw`, если тот включён.
3. Проверьте:
   ```bash
   systemctl status nitrorush-server      # должно быть active (running)
   journalctl -u nitrorush-server -f      # лог: подключения, старты, финиши
   ss -ulpn | grep 24680                  # порт слушается
   ```

## Настройки

`sudo nano /etc/default/nitrorush`, затем `sudo systemctl restart nitrorush-server`.

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `NAME` | Nitro Rush сервер | название в списке игр и в лобби |
| `PORT` | 24680 | UDP-порт (поменяли — поправьте проброс и пишите в игре `адрес:порт`) |
| `MAX_PLAYERS` | 8 | максимум игроков (2–16) |
| `BOTS` | 3 | ботов в новом лобби (0–6) |

## Как идёт игра

- Первый подключившийся становится **лидером лобби** (★). Он выбирает трассу, круги, ботов и время суток и жмёт «СТАРТ ГОНКИ».
  Если лидер выходит, роль переходит следующему игроку.
- Во время гонки новые игроки не пускаются, они получают сообщение «Гонка уже идёт».
- Сервер сам возвращает всех в лобби: через 8 с после финиша всех игроков, через 60 с после первого финиша
  или по общему лимиту времени.

## Обновление и удаление

- **Обновление:** скачайте архив нового релиза и снова выполните `sudo ./install.sh`. Настройки сохранятся.
- **Остановка:** `sudo systemctl stop nitrorush-server`. Отключение автозапуска: `sudo systemctl disable nitrorush-server`.
- **Удаление:**
  ```bash
  sudo systemctl disable --now nitrorush-server
  sudo rm -rf /opt/nitrorush /etc/default/nitrorush /etc/systemd/system/nitrorush-server.service
  sudo userdel -r nitrorush
  ```

## Если не подключается

| Симптом | Что проверить |
|---|---|
| «Не удалось подключиться» из дома | `systemctl status nitrorush-server`; IP платы; `sudo ufw status` |
| Дома работает, через интернет нет | белый ли IP; проброс именно **UDP**; подключаться надо с мобильного интернета, а не изнутри той же сети (многие роутеры не поддерживают NAT loopback) |
| «Версия игры не совпадает» | обновите APK и сервер до одного релиза |
| Сервер не стартует, «не удалось открыть UDP-порт» | порт занят (`ss -ulpn`) или указан порт ниже 1024 |
| Лагают машины соперников | слабая отдача у интернета платы; уменьшите число ботов и игроков |

## Ручной запуск (без установки)

```bash
./NitroRushServer.arm64 --headless -- --server --port=24680 --name="Мой сервер" --max-players=8 --bots=3
```
