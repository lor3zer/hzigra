# Nitro Rush — аркадные гонки для Android и iPhone

Нативная мобильная игра на **Godot 4.3** (GDScript). Не HTML: на Android это обычный APK,
на iPhone — обычное приложение из Xcode.

## Что есть в игре

| Режим | Описание |
|---|---|
| **Гонка** | Настраивается в меню: трасса, направление (прямое/обратное), 1–10 кругов, 0–7 соперников, сложность ботов, время суток (день/закат/ночь), столкновения вкл/выкл. Позиции, время круга, рекорды трасс сохраняются. |
| **Песочница** | Свободная езда по любой карте без правил, можно добавить ботов на трассу и **менять машину прямо на ходу** (пауза → «Сменить машину»). |
| **Мультиплеер (Wi-Fi)** | До 8 игроков в локальной сети: автопоиск игр, лобби, хост настраивает гонку, можно добавить ботов. |
| **Гараж** | 20 машин: 10 класса **Спорт** и 10 класса **Гипер**, 10 цветов окраски, характеристики (скорость, 0–100, управляемость, сцепление). |

**Карты:** Зелёная долина, Песчаная буря (пустыня), Снежный перевал, Ночной город, Прибрежное кольцо,
а также открытый **Полигон** (дрифт-круг, слалом, восьмёрка).

**Управление:** экранные кнопки (руль ◀ ▶, газ, тормоз, нитро) или наклон телефона (настраивается,
есть калибровка и инверсия). На ПК: WASD/стрелки, Space — нитро, R — вернуться на трассу, C — камера,
Esc — пауза. Геймпад тоже поддерживается.

**Трассы:** извилистые конфигурации со шпильками, шиканами и связками (12–19 крутых поворотов на трассу),
трибуны со зрителями у самых опасных поворотов, девушка с флагами даёт старт.
Вокруг трасс: леса из елей и лиственных деревьев, кусты, камни, трава, деревни из хижин и домов,
саманные дома в пустыне, избы в снегу, пальмы и пляжные домики у моря, небоскрёбы в городе.

**Текстуры:** асфальт, трава, песок, снег, гравий, бетон, дерево, штукатурка, черепица, фасады,
протектор шин, карбон, решётки, фары. Всё процедурное и сжатое, около 300 КБ на весь набор.

**Звук:** моторы рендерятся физической моделью (цилиндры с впускными и выпускными трубами,
коллектор, глушитель): рядные 4 и 6 с турбиной, оппозитная 6, V8 кросс-плейн и флэт-плейн,
V10, V12, W16, электро. Коробка передач, отсечка, турбина и перепускной клапан, выстрелы с огнём
из выхлопа, визг шин, ветер, удары. Атмосфера по трассе: птицы, сверчки ночью, город, море и чайки,
ветер, шум толпы у трибун. Фоновая музыка играет плейлистом, громкость музыки и звуков настраивается отдельно.

**Тюнинг (в гараже):** одинаковый набор для всех машин: антикрыло, передний бампер (сплиттер или агрессивный),
карбоновые пороги, диффузор, капот (с жабрами или карбоновый), диски и их цвет.
Тюнинг виден другим игрокам в мультиплеере.

**Машины:** кузова строятся из сечений по профилям стиля, с арками колёс, остеклением и стойками.
Швы дверей, капота и бамперов нанесены текстурой, а не геометрией.
Всего 12 силуэтов: хэтчбек, маслкар, GT, JDM-купе, заднемоторное купе, седан, среднемоторный, родстер,
гиперкар-клин, обтекаемый гиперкар, лонгтейл и прототип Ле-Мана.

### Генераторы ресурсов (`tools/`, в сборку не попадают)

```bash
python3 tools/gen_textures.py                     # textures/*.jpg|png
ENGINESOUND=<путь>/enginesound python3 tools/gen_engines.py   # семплы моторов
MUSIC_DIR=<папка с mp3> python3 tools/gen_audio.py # audio/*, музыка, scripts/data/engine_db.gd
python3 tools/track_preview.py <папка>            # проверка геометрии трасс и схемы PNG
```
Синтезатор моторов взят из [DasEtwas/enginesound](https://github.com/DasEtwas/enginesound) (MIT), он основан на статье
«Physically informed car engine sound synthesis for virtual and augmented environments».
Собирается так: `cargo build --release --no-default-features`.

```

  data/track_db.gd     трассы (контрольные точки сплайна + тема оформления)
  world/track.gd       генерация трассы: дорога, поребрики, отбойники, декорации, небо
  car/car.gd           аркадная физика машины, круги, сетевая интерполяция
  car/car_model.gd     low-poly модель машины из примитивов
  car/ai_driver.gd     ИИ-пилот (профиль скоростей, обгоны)
  car/engine_sound.gd  звук машины: слои мотора, турбина, выстрелы, шины
  autoload/music.gd    фоновая музыка (плейлист)
  world/scenery.gd     декорации: деревья, кусты, трава, дома, хижины
  world/stands.gd      трибуны со зрителями
  world/start_girl.gd  стартовая девушка с флагами
  data/engine_db.gd    параметры моторов (генерируется tools/gen_audio.py)
  race/race.gd         заезд: правила, камера, столкновения, сеть
  ui/                  меню, HUD, сенсорное управление, миникарта
audio/                 звуки и музыка (ogg)
textures/              процедурные текстуры
tools/                 генераторы текстур, звуков, проверка трасс
tests/                 headless-тесты и запись демо (в сборку не попадают)
```

## Как собрать

### Android (APK)

**Вариант 1 — GitHub Actions.** Workflow `.github/workflows/android-apk.yml` собирает APK
при каждом пуше в `racing-game/`. Готовый файл лежит в *Actions → запуск → Artifacts → NitroRush-apk*.
Чтобы обновления ставились поверх старой версии, добавьте в секреты репозитория свой keystore:
`ANDROID_KEYSTORE_BASE64` (`base64 -w0 my.keystore`), `ANDROID_KEYSTORE_USER`, `ANDROID_KEYSTORE_PASSWORD`.
Без секретов каждая сборка подписывается новым ключом: перед установкой удалите старую версию.

**Вариант 2 — локально.**
1. Установите [Godot 4.3](https://godotengine.org/download/archive/4.3-stable/) и шаблоны экспорта
   (*Editor → Manage Export Templates*).
2. *Editor Settings → Export → Android*: путь к Android SDK и JDK 17+.
3. *Project → Export → Android → Export Project* → `NitroRush.apk`.
4. Скопируйте APK на телефон и установите (разрешите установку из неизвестных источников).

### iPhone

Сборка под iOS по правилам Apple возможна **только на Mac с Xcode**: HTML для этого не нужен.
1. На Mac откройте проект в Godot 4.3, установите шаблоны экспорта.
2. *Project → Export → iOS*: укажите `App Store Team ID` (ваш Apple ID в Xcode → Settings → Accounts),
   при необходимости поменяйте `Bundle Identifier` на уникальный.
3. Экспортируйте Xcode-проект, откройте его в Xcode, подключите iPhone и нажмите **Run**.
   - С бесплатным Apple ID приложение работает 7 дней, потом его нужно переустановить из Xcode.
   - С платным аккаунтом разработчика ($99/год) можно раздавать игру через TestFlight.
4. При первом запуске мультиплеера iOS спросит доступ к «Локальной сети»: нужно разрешить.

Если Mac нет, можно использовать облачные macOS-сборщики (например, Codemagic или GitHub Actions с macOS-раннером),
но для установки на телефон всё равно понадобится Apple ID для подписи.

## Выделенный сервер (Armbian и другие Linux)

Сервер для игры через интернет или домашнюю сеть без телефона-хоста: консольная сборка без графики
для arm64, armhf и x86_64, автозапуск через systemd. Архивы лежат в Releases, установка — `sudo ./install.sh`.
Требования к железу и сети, проброс порта, DDNS и решение проблем описаны в [server/SERVER.md](server/SERVER.md).

## Мультиплеер: как играть

1. Все устройства подключены к одному Wi-Fi или к точке доступа одного из телефонов.
2. Один игрок нажимает **Мультиплеер → Создать игру**: он становится хостом.
3. Остальные видят игру в списке «Найденные игры» или вводят IP хоста, который показан в лобби.
   К выделенному серверу подключаются по адресу (`IP`, `домен` или `домен:порт`).
4. Хост (на выделенном сервере — лидер лобби ★) выбирает трассу, круги и ботов и нажимает **СТАРТ ГОНКИ**.

Порты: UDP 24680 (игра) и UDP 24681 (поиск игр).

> **Про iPhone:** iOS без специального разрешения Apple (multicast entitlement) блокирует
> широковещательные пакеты, поэтому iPhone может не увидеть игру в списке. Подключение
> **по IP** работает всегда: хост видит свой IP в заголовке лобби.

## Тесты

```bash
# геометрия трасс, полный заезд ботов на каждой карте, все экраны меню
godot --headless --fixed-fps 60 --path . res://tests/sim_test.tscn

# мультиплеер: два процесса на одной машине
godot --headless --max-fps 60 --path . res://tests/net_test.tscn -- host &
godot --headless --max-fps 60 --path . res://tests/net_test.tscn -- client
```
